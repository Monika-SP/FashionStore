# FashionStore 🛍️

A full-stack fashion e-commerce web application built with **Python, Django, MySQL, HTML, CSS, and JavaScript**.

FashionStore provides a simple and modern online shopping experience with product browsing, user authentication, wishlist, shopping cart, checkout, and order management.

---

## ✨ Features

- 🏠 Modern fashion-focused homepage
- 👗 Separate Women, Men, and Accessories collections
- 🔎 Product search and category filtering
- 🛍️ Product details with size selection
- ❤️ Wishlist functionality
- 🛒 Shopping cart with quantity controls
- 💳 Checkout and order placement
- 📦 Order history and order details
- 👤 User registration, login, logout, and profile
- 🗄️ MySQL database integration
- 📱 Responsive design for desktop and mobile
- 🎨 Interactive UI using HTML, CSS, and JavaScript
- 🔐 Django authentication for user accounts
